MP3 to Text Transcriber

runs 100% in your browser — nothing is uploaded

Upload an MP3 (or WAV, M4A, OGG, FLAC) and get a transcript with timestamps, powered by OpenAI Whisper running locally in your browser. English and Chinese supported, plus auto-detect.

No server, no API key. The first run downloads the Whisper model (75–500 MB depending on size) and caches it in your browser, so later runs start instantly. Large files over 200 MB work too — they are processed in 10-minute chunks, so the transcript grows as it goes.
